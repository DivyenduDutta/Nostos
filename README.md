# Nostos

A Three.js exploration of Homer's *Odyssey* — an interactive map of Odysseus's route from Troy to Ithaca, where each stop reveals a particle-art illustration of that episode. Inspired by [chartogne-taillet.com](https://chartogne-taillet.com)'s particle-cloud terroir map, reimagined around the *Odyssey* instead of a vineyard.

## Setup

```bash
npm install
npm run dev
```

## Status

Skeleton only: Vite + Three.js scene with a placeholder particle-reveal animation (scatter → sphere). Next up is swapping the placeholder sphere for the real image-sampled particle system.
